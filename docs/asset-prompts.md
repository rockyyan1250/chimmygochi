# 画像生成AI用プロンプト集（CHIMMY GOCHI v0.1）

このファームウェアで使う画像を、すべて画像生成AIで作るためのプロンプト集。
キャラクター画像は1回に1枚ずつ生成する。毎回、基準画像（黄色いフードの立ち姿）を添付し、
「共通プロンプト」の最後の行を、各素材の「個別指示」に差し替えて渡す。

生成した画像は `assets/chimmy/raw/<素材名>.png` に保存し、`npm run prep-images` で整形する。
手順の詳細は [operation.md](operation.md) の「画像生成AIの出力を整形する」を参照。

## 0. 必要な画像の一覧

ファームウェアの制約：1衣装あたり画像は最大12枚、アニメーションは8枠、衣装は3種類、背景は1枚。

| # | 素材名 | 内容 | 使うアニメーション |
|---|---|---|---|
| 0 | `stand_normal` | 基準の立ち姿 | 待機（基本） |
| 1 | `stand_blink_closed` | 目を閉じる | 待機（まばたき） |
| 2 | `stand_curious` | 「ん？」 | タップ |
| 3 | `stand_happy` | 嬉しい笑顔 | 喜ぶ、着替え |
| 4 | `cheer` | 両手を上げて喜ぶ | 喜ぶ |
| 5 | `food_ready` | ごはんを待つ | 食事 |
| 6 | `stand_satisfied` | 満足 | 食事 |
| 7 | `hold_ball` | ボールを抱える | 遊び |
| 8 | `jump` | 小さくジャンプ | 遊び |
| 9 | `sleep_curl` | 丸くなって眠る | 睡眠（繰り返し） |
| 10 | `wave` | 手を振る | 着替え |
| 11 | `stand_refuse` | いやいや、と断る | 断る |
| — | `room` | 部屋の背景 480×480 | 全画面の背景 |

アニメーションは、上の静止画をパラパラ漫画のように切り替えて作る。
割り当てと表示時間は `assets/chimmy/chimmy.json` の `clips` で決まっている。

| アニメーション | いつ再生されるか | コマの順番（表示時間） |
|---|---|---|
| idle（待機） | 普段、繰り返し | 0（2.6秒）→ 1（0.15秒） |
| tap | キャラクターをタップ（親密度40未満） | 2 → 0 |
| happy | タップ（親密度40以上）、泡遊び完了 | 3 → 4 → 3 → 4 |
| eat | 食事 | 5 → 6 → 5 → 6 |
| play | ボール遊び | 7 → 8 → 7 → 8 |
| sleep | 睡眠中、繰り返し | 9 |
| dress | 着替え | 10 → 3 → 10 |
| refuse | 満腹・睡眠中・疲れているときに断る | 11 → 0 |

### 生成する順番

1. **最初の3枚**：`stand_normal`、`stand_blink_closed`、`stand_happy`。
   整形して実機に入れ、256pxの画面でCHIMMYに見えるかを確認する。ここで絵柄を決める。
2. **残りの立ち絵**：`stand_curious`、`stand_satisfied`、`stand_refuse`。
3. **ポーズ**：`wave`、`cheer`、`food_ready`、`hold_ball`、`jump`、`sleep_curl`。
4. **背景**：`room`。
5. **衣装違い**（任意）：最後に。作らない場合は、3衣装とも同じ画像を使う。

まだ無い画像は、整形ツールが `stand_normal` で代用するので、途中でも実機で確認できる。

## 1. 共通プロンプト（キャラクター画像用）

```
あなたは、2D育成ゲーム用のキャラクター素材を制作するイラストレーターです。

添付画像を唯一のキャラクターデザイン基準として、同じキャラクターの表情・ポーズのバリエーションを1枚作成してください。
新しいキャラクターをデザインしたり、絵柄を変更したりする依頼ではありません。

■ 目的
小型の丸い画面（480×480）で動く育成ゲームのキャラクター画像です。
最終的に256×256ピクセルへ縮小し、複数の画像を切り替えてアニメーションにします。
画像を切り替えても、同じキャラクターが同じ大きさ・同じ位置にいるように見える必要があります。

■ 必ず維持するデザイン
・大きな頭と小さな体の比率
・黄色いフードと、左右の黒い垂れ耳
・白い顔、額の黒い線で描かれた巻き毛
・黒い目、黒い鼻、口の基本的な描き方
・左右の淡いピンク色の丸い頬
・黄色いつなぎ服、胸元に縦に並んだ赤橙色のボタン2個
・白い手先と足先
・丸く柔らかいシルエット
・基準画像と同じ太さの黒い輪郭線と配色

細部に迷った場合は、文章から新しく補うより、添付画像を優先してください。

■ 絵柄
基準画像と同じ、かわいい2Dカラーイラスト。
塗りは平らな単色で、粒状の質感・ノイズ・グラデーションは入れないでください。
ドット絵、写実的な絵、3Dレンダリング、ぬいぐるみの写真にはしないでください。
強い光沢、立体的な陰影、毛並みは加えないでください。

■ サイズと構図
・正方形、1024×1024ピクセル。対応していない場合は利用可能な正方形サイズ。
・キャラクターは1体だけ。耳、手、足を含む全身を画面内に収める。
・縮小しても、目、口、手足が分かるようにする。細かい描き込みは避ける。
・文字、名前、ロゴ、枠、透かしは入れない。

■ 配置
立ち姿：キャラクターの高さはキャンバスの約75％。左右中央。足元は上端から約87.5％の高さ。
姿勢が変わる場合：基準の立ち姿と比べて、頭や体そのものを拡大・縮小しない。
ポーズによる縦横の広がりは、周囲の余白で調整する。
表情だけを変える場合：ポーズ、頭の向き、大きさ、配置は基準画像と同じにし、顔のパーツだけを変える。

■ 背景
背景は真っ白（#FFFFFF）の無地で塗りつぶしてください。
透過を表す市松模様、床、落ち影、グラデーション、背景装飾は描かないでください。
指定していない小物、星、ハート、効果線、吹き出しも加えないでください。

■ 優先順位
1. 基準画像と同じキャラクターに見えること
2. 指定した表情・ポーズが分かること
3. 大きさと配置が基準画像とそろっていること
4. 装飾を増やすより、シンプルであること

■ 出力
指定した表情またはポーズの完成画像を1枚だけ。
複数ポーズの一覧、コンタクトシート、スプライトシートにはしないでください。

■ 今回作成する素材
【ここに個別指示を入れる】
```

> 背景を「透過」ではなく「真っ白」にしているのは、多くの画像生成AIが透過を指示されても
> 白背景や偽の市松模様を描くため。白い背景は整形ツールが自動で透過にする。

## 2. 個別指示

### 0. stand_normal（基準の立ち姿）

```
素材名：stand_normal

添付画像と同じ立ち姿・表情を、上記の条件（白い無地の背景、1024×1024、配置）で描き直してください。
ポーズ、表情、デザインは一切変えないでください。
これは他のすべての画像の大きさと位置の基準になります。
```

### 1. stand_blink_closed（まばたき）

```
素材名：stand_blink_closed

まばたき用の1コマです。変更するのは左右の目だけです。
目を、自然に閉じた短い下向きの弧の線にしてください。

口、鼻、頬、巻き毛、顔の輪郭、耳、衣装、手足、キャラクターの位置と大きさは変更しないでください。
笑顔や眠っている表情にはしないでください。
```

### 2. stand_curious（「ん？」）

```
素材名：stand_curious

基準画像と同じ立ち姿のまま、「ん？」と何かに気づいた表情にしてください。
目は基準画像と同じ丸い形のまま少しだけ大きくし、口は小さな丸い形にしてください。

頭を傾けず、体と手足も動かさないでください。
疑問符や文字は不要です。
```

### 3. stand_happy（嬉しい笑顔）

```
素材名：stand_happy

基準画像と同じ立ち姿のまま、嬉しい表情にしてください。
両目を上向きの弧の形にやさしく細め、口元を小さく開いた笑顔にしてください。
鼻、巻き毛、頬の位置は維持してください。

頭や体を傾けず、腕や脚も動かさないでください。
```

### 4. cheer（両手を上げて喜ぶ）

```
素材名：cheer

正面を向いて立ち、両手を斜め上へ上げて喜んでいる姿にしてください。
両足は地面についたまま。両手で顔や耳を隠さないでください。
表情は、目を嬉しそうに細めて小さく口を開けた笑顔。

頭と体の大きさ、足元の位置は基準画像と同じにしてください。
星、ハート、効果線は追加しないでください。
```

### 5. food_ready（ごはんを待つ）

```
素材名：food_ready

正面を向いて立ち、両手をおなかの前へ少し出して、ごはんを受け取る準備をしている姿にしてください。
左右の白い手先の間に、小さなおにぎりが入るくらいの余白を残してください。
表情は、丸い目のまま口元を少し開けて、期待している穏やかな笑顔。

食べ物そのものは描かないでください。
顔と口を手で隠さないでください。
頭と体の大きさ、足元の位置は基準画像と同じにしてください。
```

### 6. stand_satisfied（満足）

```
素材名：stand_satisfied

基準画像と同じ立ち姿のまま、食事を終えて満足している表情にしてください。
目を穏やかな弧の形に細め、口元を小さく微笑ませてください。
頬のピンク色を少しだけ濃くしてください。

体やおなかを大きくしないでください。
食べ物や食べかすは追加しないでください。
```

### 7. hold_ball（ボールを抱える）

```
素材名：hold_ball

正面を向いて立ち、小さな無地の水色のボールを両手で胸の前に抱えている姿にしてください。
ボールの大きさは顔の半分くらい。顔と胸元のボタンの上半分を隠さないでください。
両腕と白い手先が、ボールの左右へ自然につながるようにしてください。
表情は嬉しい笑顔。

頭と体の大きさ、足元の位置は基準画像と同じにしてください。
ボール以外の小物は追加しないでください。
```

### 8. jump（小さくジャンプ）

```
素材名：jump

その場で小さくジャンプしている途中の姿にしてください。
両脚を軽く曲げ、両手を少し上げてください。
表情は正面を向いた嬉しそうな笑顔。

頭と体の大きさは基準画像と同じにしてください。体を伸ばさず、丸い体型を維持してください。
キャラクター全体を、基準画像の位置から体の高さの約10％だけ上へ移動してください。
耳や手が画面外に切れないようにしてください。
床、影、効果線は不要です。
```

### 9. sleep_curl（丸くなって眠る）

```
素材名：sleep_curl

体を横にして、丸くなって眠っている姿にしてください。
頭は画像の左側、足は右側。
顔は完全な真横ではなく、閉じた目と鼻が見える程度にこちらへ向けてください。
両手は顔の近くへ自然に寄せてください。

頭や耳の大きさ、衣装、配色、絵柄は基準画像とそろえてください。
体の一番下を、基準画像の足元と同じ高さ（上端から約87.5％）に置いてください。
ボタンが姿勢で隠れる場合は、無理に見える位置へ移動しないでください。
ベッド、枕、布団、「Zzz」などの眠る記号は追加しないでください。
```

### 10. wave（手を振る）

```
素材名：wave

正面を向いて立ち、画像を見る人から見て右側の手を上げて、手を振っている姿にしてください。
反対側の腕は自然に下ろしてください。
上げた手は顔や耳に重ならない位置にしてください。
白い手先は基準画像と同じ簡潔な形にし、指を描き込まないでください。
表情はやさしい笑顔。

頭と体の大きさ、足元の位置は基準画像と同じにしてください。
```

### 11. stand_refuse（断る）

```
素材名：stand_refuse

基準画像と同じ立ち姿で、「いやいや」と小さく断っている表情にしてください。
目をぎゅっと閉じて「><」のような形にし、口は小さく結んだ波線にしてください。
頬をほんの少しふくらませてください。

怒った顔、泣いた顔、悲しい顔にはしないでください。かわいく断る程度です。
頭をほんの少しだけ横に傾けてもかまいませんが、体と手足は動かさないでください。
汗、怒りマーク、文字は追加しないでください。
```

## 3. 背景（room）

背景はキャラクター用の共通プロンプトを使わず、これ単体で渡す。基準画像は絵柄の参考として添付する。

```
添付画像のキャラクターと同じ絵柄（太めの黒い輪郭線、平らな淡い色の塗り）で、
キャラクターが住んでいる小さな部屋の背景イラストを1枚作成してください。
キャラクター自身は描かないでください。

■ サイズ
正方形、1024×1024ピクセル（ゲームで480×480に縮小します）。

■ 構図
・正面から見た、シンプルで明るい子ども部屋。
・画面の下から約40％が床、その上が壁。床と壁の境目は水平。
・画面の中央（左右中央、上下は20％〜70％の範囲）には何も置かないでください。
  ここにキャラクターが立ちます。
・家具や小物は左右の端に寄せてください。例：左の壁に窓、右の床に小さな観葉植物。
・画面の上端から12％と、下端から25％の範囲には、ボタンや文字が重なります。
  ここには目立つものや細かいものを置かないでください。

■ 色
・クリーム色、淡いミント、淡いピンクなど、明るく低い彩度の色。
・キャラクターの黄色と黒がはっきり見えるように、黄色と黒は背景に大きく使わないでください。
・グラデーション、粒状の質感、強い影は使わず、平らな塗りにしてください。

■ 禁止
文字、ロゴ、枠、透かし、人物、動物、キャラクター。
```

生成した画像は `assets/chimmy/raw/room.png` として保存し、
`chimmy.json` の `background` を `raw/room.png` に変更する。
`prep-images` が480×480へ自動で縮小する（正方形でなければ中央を切り抜く）。

## 4. 衣装違い（任意）

ファームウェアは衣装を必ず3種類持つ。作らない場合は3衣装とも同じ画像を使う（初期設定）。
作る場合は、1衣装につき上の12枚すべてが必要で、合計24枚増える。
新しく描かせるより、作成済みの画像を1枚ずつ添付して「服だけ変える」編集をさせるほうが、ずれにくい。

```
添付画像のキャラクターの、服装だけを変更した画像を1枚作成してください。

【変更する部分】
【ここに衣装の指示を入れる】

【維持する部分】
顔、表情、目、口、頬、巻き毛、耳、ポーズ、手足の位置、輪郭線の太さ、絵柄。
キャラクターの位置と大きさ、キャンバスのサイズ、白い無地の背景。

服の変更に必要な箇所以外は、添付画像とまったく同じにしてください。
文字、効果線、小物は追加しないでください。
```

衣装の指示の例（黒い垂れ耳と白い顔は変えない）：

- **パジャマ**：「黄色いつなぎ服を、淡い水色に白い水玉のパジャマに変更してください。フードは黄色のまま。胸のボタン2個は白に変更してください。」
- **マフラー**：「首に赤いチェック柄の短いマフラーを巻いてください。マフラー以外の服は変えないでください。」

衣装違いは `assets/chimmy/outfit1/`、`assets/chimmy/outfit2/` に同じファイル名で保存し、
`chimmy.json` の `outfits` の `dir` と `name` を変更する。
衣装名に新しい文字を使った場合は、`npm run build` と `npm run upload` も必要。

## 5. 確認のポイント

`npm run prep-images` の後、`assets/chimmy/preview.png` で次を確認する。

- 赤い線（足元）と青い線（中心）に対して、立ち絵の位置がそろっているか。
  ずれていると、待機アニメのまばたきでキャラクターが揺れて見える。
- 頭の大きさが、画像ごとに変わっていないか。変わっていれば `chimmy.json` の `scale` で調整する。
- 背景の白が残っていないか（特に腕と体の間）。残っていれば `holes` で指定する。
- 耳や手が切れていないか（ツールが警告を出す）。

生成AIがうまく従わない場合は、同じ指示で数回生成し、基準画像に一番近いものを選ぶ。
食べ物と玩具の絵は、今のファームウェアには表示する仕組みがないので、まだ作らなくてよい。
