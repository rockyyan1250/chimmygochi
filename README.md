# chimmygochi

BT21のBABY CHIMMYを主人公とする計画の、Waveshare ESP32-S3-Touch-AMOLED-2.16向け育成ゲーム・待ち受け。
Arduino / LVGLによる実機用プロトタイプを収録しています。
キャラクター画像はSD上の素材パックで差し替えます。リポジトリにCHIMMYの公式素材は含みません。

## 使い方

操作は文字ではなくアイコンで行います。ボタンや文字は、液晶の丸い角に掛からない位置に置いています。

- 家 / 肉球のアイコンで、育成画面と待ち受け画面（キャラクターと小さな時計）を切り替えます。
  待ち受けでは、キャラクターが部屋の中をゆっくり歩いたり座ったりします。
- キャラクターに触ると、6種類の表情・しぐさからランダムに反応します。
- 左上の月 / 太陽で睡眠・起床、右上の歯車で設定。死亡・病気はありません。
- 育成画面のおにぎりで食事（6種類）、ボールでボール・泡遊び、額縁で背景（最大3種類）を選びます。
- 満腹・疲れているときは、キャラクターが「いやいや」のアニメーションで断ります。
- 上部中央に電池残量の推定値を表示します。USB給電中はプラグ、充電中は雷の印が付きます。
  未接続は `--`、取得エラーは `ERR` で、数値にしません。
- 無操作2分で消灯。画面タッチまたはPWR短押しで復帰します。
- **電池仕様が未確認のため、主電池・バックアップ電池の充電は無効化しています。**

[詳しい操作・製作・素材差し替え・復旧手順](docs/operation.md)

## ビルド・転送

Windows または macOS、Node.js 22.12以上、Arduino IDE 2（同梱CLI）/ ESP32 core 3.3.12が必要です。
既存Flashのバックアップと接続先の確認を済ませてから書き込んでください。

```sh
npm ci
npm run setup
npm run assets
npm run check
npm run build
npm run upload
npm run device -- time
npm run device -- install
npm run device -- status
```

USBポートはESP32-S3（VID 303A）を自動検出します。複数ある・見つからない場合は
環境変数 `PORT`（例：`COM3`、`/dev/cu.usbmodem2301`）を指定します。素材転送は既存ファイルを上書きせず、
新規パックの検証後に切り替えます。SDカードのフォーマットは行いません。
